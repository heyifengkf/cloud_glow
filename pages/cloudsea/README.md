# 云海预测（cloudsea）

本页面预测当前选中位置是否会出现**云海**，并给出出现概率。

## 核心判据

云海 = **低云在谷地铺开，且云顶高度低于观测点海拔**（人站在云上）；逆温层是云海稳定持久的保障。

## 数据来源

| 数据 | 接口 | 字段 | 单位 |
|------|------|------|------|
| 观测点海拔 `H_obs` | `api.open-meteo.com/v1/elevation` | `elevation[0]` | 米（约 90m DEM） |
| 各层位势高度 | forecast `models=...` | `geopotential_height_*hPa` | 米 |
| 各层云量 | 同上 | `cloud_cover_*hPa` | % |
| 各层相对湿度 | 同上 | `relative_humidity_*hPa` | % |
| 各层温度 | 同上 | `temperature_*hPa` | ℃ |
| 地面风速 | 同上 | `wind_speed_10m` | m/s |
| 近地面湿度 | 同上 | `relative_humidity_2m` | % |

气压层沿用 `request.LEVELS_HPAS[model]`（ec 13 层 / gfs 17 层 / icon 19 层）。

## 算法步骤（逐预报时刻）

### ① 云层识别与云顶/云底

```
isCloud(p) = (cloud_cover_p ≥ 35%) OR (relative_humidity_p ≥ 88%)

从最低气压层向上扫描连续云段：
  遇到「连续 2 层无云」或「相邻云层高度差 > 800m」即截断

H_base = 云段最低层位势高度
H_top  = 云段最高层位势高度
C      = 云段内最大云量
```

### ② 高度门控 `S_height`（乘性硬门控）

`Δ = H_obs − H_top`（米）：

| Δ 范围 | S_height |
|---------|----------|
| ≤ −200 | 0 |
| −200 ~ 0 | 线性 0 → 0.4 |
| 0 ~ 300 | 1 |
| 300 ~ 1500 | 线性 1 → 0.5 |
| > 1500 | 线性 0.5 → 0 |

### ③ 云量门控 `S_cover`（乘性硬门控）

梯形函数，以 `C`（%）为输入：

| C 范围 | S_cover |
|--------|---------|
| 0 ~ 30% | 线性 0 → 1 |
| 30% ~ 90% | 1 |
| 90% ~ 100% | 线性 1 → 0.3 |

### ④ 逆温稳定因子 `S_inversion`

在 `[H_top, H_obs]` 区间内对相邻层正温差求和：

```
INV = Σ max(0, T上 − T下)
```

| INV (℃) | S_inversion |
|----------|-------------|
| ≤ 0 | 0.25 |
| 0 ~ 2 | 线性 0.25 → 0.75 |
| 2 ~ 6 | 线性 0.75 → 1 |
| > 6 | 1 |

### ⑤ 低层湿度因子 `S_humid`

以 `RH₀ = relative_humidity_2m`（%）为输入：

| RH₀ | S_humid |
|-----|---------|
| < 60% | 0.2 |
| 60% ~ 95% | 线性 0.2 → 1 |
| ≥ 95% | 1 |

### ⑥ 风速因子 `S_wind`

以 `W = wind_speed_10m`（m/s）为输入：

| W (m/s) | S_wind |
|---------|--------|
| ≤ 2 | 1 |
| 2 ~ 8 | 线性 1 → 0.4 |
| 8 ~ 15 | 线性 0.4 → 0.05 |
| > 15 | 0.05 |

### ⑦ 合成云海指数

```
S = S_height × S_cover × (0.35·S_inversion + 0.30·S_humid + 0.35·S_wind)
```

- `S_height`、`S_cover` 为乘法门控（任一为 0 → 整体 0）
- 后三项为加权调节因子

### ⑧ 概率校准（Sigmoid）

```
P = 1 / (1 + exp(−k·(S − θ)))，k = 6，θ = 0.45
```

### ⑨ 分级与输出

| P | 等级 |
|---|------|
| < 20% | 不太可能 |
| 20% ~ 40% | 低 |
| 40% ~ 60% | 中等 |
| 60% ~ 80% | 较高 |
| ≥ 80% | 极高 |

对 72 小时逐时刻计算后，页面展示：未来 24 小时最佳窗口（含峰值概率与关键因子：云顶/云底、逆温、云量、风速、湿度）、未来 24 小时海拔-云层高度剖面图（橙色虚线为观测点海拔、青色色块为云层，纵轴 0–4000m）、未来 24 小时逐时概率柱状图。
